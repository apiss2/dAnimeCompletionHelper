# dAnimeCompletionHelper

dアニメストアで指定した範囲の話を、まとめて視聴済みにする Chrome / Microsoft Edge 拡張機能です。
動画の再生や別タブの起動はしないまま動作します。

## インストール

1. GitHub の「Code」→「Download ZIP」からダウンロードし、ZIPを展開
2. Chrome で `chrome://extensions`（Edge は `edge://extensions`）を開き、「デベロッパーモード」を有効化
3. 「パッケージ化されていない拡張機能を読み込む」を押し、`manifest.json` が入っているフォルダーを選択

読み込んだフォルダーは、拡張機能を使っている間は同じ場所に保管してください。

## 使い方

1. 作品ページを開く（表示されない場合は再読み込み）
2. 「気になる登録数」の下にある「まとめて視聴済み登録」を押す
3. 開始話と終了話を、表示された話数・タイトルの一覧から選び、「登録」を押す

処理が完了したら、作品ページが自動で再読み込みされて表示が更新されます。
同じボタンをもう一度押すか、Escape キーを押すと操作欄を閉じられます。

## 停止とエラー

- 「停止」を押すと、後続の通信を中断します。すでに送信済みの更新は取り消せません。
- エラーが出た場合や、送信後に視聴済み状態を確認できない場合は、処理を停止します。
- エラーの場合再読み込みされないため、視聴状態が画面に反映されない可能性があります。

## 更新

処理を停止してから、読み込んだフォルダーのファイルを最新版で上書きします。
拡張機能の管理画面で再読み込みボタンを押し、dアニメストアの作品ページも再読み込みしてください。
（GitHubからCloneしておくと更新が便利です）

## 注意点

- サイトの仕様変更によって動作しなくなる場合があります。
