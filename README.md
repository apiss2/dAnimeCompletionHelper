# dAnimeCompletionHelper（非公式）

Chrome / Microsoft Edge (Manifest V3) 用拡張機能です。

## インストール

1. ZIP を展開します。
2. Chrome の `chrome://extensions` （Edge は `edge://extensions`）を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、**manifest.json が入った `dAnimeCompletionHelper` フォルダー**を選びます。
5. dアニメストアの作品ページ（例：`https://animestore.docomo.ne.jp/animestore/ci_pc?workId=28572`）を再読み込みします。

## 操作

1. 作品ページ右下の「dAnimeCompletionHelper」から、開始話と終了話を設定します。
2. 各話の再生秒数を指定します（初期値15秒、5～60秒）。
3. 「指定範囲を再生」を押します。専用のタブで対象話数を順に開きます。
4. 動画の再生進行を所定時間検出した場合に次の話へ移動します。自動再生は原則無音です。
5. 元の作品ページに進行状況が表示されます。「停止」で中断できます。

**例**：「正反対な君と僕」の第1～13話を再生するには開始話1、終了話13を入力します。

## 制限・注意

- **未検証版です。** 利用者のログイン状態での動画再生、視聴済み表示が実際に戻ることは検証できていません。
- この拡張機能が確認するのは HTML5 `<video>` の実際の再生進行であり、dアニメストアのサーバーで視聴済み登録されたかどうかではありません。公式には「コンプリート」登録に必要な再生秒数は明示されていません。登録されなければ再生秒数を増やし、1話で挙動を確認してください。
- HTML5 動画がこのドメイン外のフレームや非公開プレーヤーにある場合、動画を検出できず停止します。再生許可が必要な場合は再生タブで手動操作が必要です。
- 再生タブを閉じると処理を停止します。拡張機能のタブ操作や DRM 制約によっては自動再生できない場合があります。
- 視聴済みの話数を自動識別する機能、サイトに視聴済みを直接登録する機能、分割クール判別はありません。
- 本拡張機能は非公式です。通信を偽装したり、アカウント認証情報を収集したり、外部サービスに送信したりしません。
- 他の視聴用拡張機能と併用すると、プレーヤーの挙動が変わる可能性があります。

## 開発・検証

Node.js で `node --test tests/episodes.test.js` を実行すると、話数とURLの抽出ロジックを検証できます。

`chrome://extensions` の「サービスワーカー」や再生タブの DevTools で問題を調べられます。特に最初は**第1話のみ**で再生が成立し、dアニメストアに視聴済み判定が付くか確認してください。
