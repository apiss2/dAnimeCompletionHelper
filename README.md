# dAnimeCompletionHelper

dアニメストアで指定した話数を順に短時間再生し、コンプリート登録を補助する非公式の Chrome / Microsoft Edge 拡張機能です。

## インストール

1. このページの「Code」→「Download ZIP」でダウンロードし、ZIP を展開します。
2. Chrome で `chrome://extensions`（Edge は `edge://extensions`）を開き、「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」で、展開した `manifest.json` が入っているフォルダーを選びます。

読み込んだフォルダーは、使っている間は同じ場所に保管してください。

## 使い方

1. dアニメストアにログインして作品ページを開きます。すでに開いている場合は再読み込みします。
2. 「気になる登録数」のすぐ下にある「まとめて視聴済み登録」ボタンを押し、開始話・終了話を指定して「再生」を押します。同じボタンをもう一度押すと操作欄が閉じます。Escape キーでも閉じられます。

別タブで各話の終了30秒前（30秒未満の動画は冒頭）へ移動し、原則無音で終端まで再生してから次の話へ進みます。進み具合とエラーは元の作品ページのパネル内に表示されます。「停止」を押すか再生タブを閉じると中断します。

## 更新

再生処理を停止し、最新版の ZIP を展開して、インストール先のファイルを上書きします。拡張機能の管理画面で再読み込みボタンを押し、dアニメストアの作品ページと再生ページも再読み込みしてください。

## 注意点

- 終盤再生による視聴済み・コンプリート表示への反映は未検証です。サイト側の判定条件は保証できません。まず1話だけで確認してください。
- 視聴済みの話数の自動判別、サイトへの直接登録、分割クールの判別には対応していません。
- 動画の埋め込み方や DRM の制約、他の拡張機能との併用によっては再生できません。再生許可を求められた場合は、再生タブで操作してください。
- 通信の偽装や、アカウント認証情報の収集・外部送信は行いません。

## 開発

Node.js を用意し、このフォルダーで `node --test` を実行すると、話数・URLの抽出と再生処理の制御を検証できます。ブラウザでの実再生や、サイト側の登録結果は別途確認してください。
