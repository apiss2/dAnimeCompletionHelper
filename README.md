# dAnimeCompletionHelper

dアニメストアで指定した範囲の視聴履歴を、動画を再生せず通信で更新する非公式の Chrome / Microsoft Edge 拡張機能です。

通信による視聴済み反映と完了後の自動リフレッシュは、ユーザーによる動作確認後にmainへ採用しました。すべての作品での動作を保証するものではありません。

## 使い方

1. Chrome の `chrome://extensions`（Edge は `edge://extensions`）で、`manifest.json` があるフォルダーを読み込みます。既存の拡張機能を更新する場合は、実行中の処理を停止し、管理画面で拡張機能を再読み込みしてください。
2. dアニメストアにログインし、作品ページを再読み込みします。
3. 「気になる登録数」の下の「まとめて視聴済み登録」を押し、開始話・終了話を指定して「登録」を押します。話数はサイトの表記にかかわらず、エピソード一覧の先頭から1、2、3…と数えた順番で指定します。同じボタンでもう一度操作欄を閉じられます。

最初は1話だけで検証してください。動画や別タブは開きません。視聴済みの話は照会だけで次へ進みます。「停止」は後続通信を中断しますが、すでに送信済みの更新は取り消せません。全件の完了後、開始元の作品ページを自動で再読み込みしてサイトの表示を更新します。停止・エラー時や、開始元のタブを閉じたり別の作品・サイトへ移動した場合は再読み込みしません。

## 調査した処理（2026-10-31）

サイトが公開している以下のコードを調べました。APIの正式な外部向け仕様ではなく、今後変更される可能性があります。

- [PlayMovie.js](https://animestore.docomo.ne.jp/js/PlayMovie.js?v=20260724233239): `WS010105` で再生情報を取得する。
- [player.min.js](https://animestore.docomo.ne.jp/js/cms/player.min.js?v=20260319174448): `updateResumePoint` が、再生情報の `resumeInfoUrl` にPOSTする。`info_type` は開始0・途中1・終了2、`playback_state` は停止0・再生1・一時停止2・開始3。位置はミリ秒、`number` は8桁の連番。
- 同プレーヤーの `sendResumePointStop`: 終了位置で終了通知を送り、500ms後に位置0で再度終了通知を送る。
- [common.js](https://animestore.docomo.ne.jp/js/cms/common.js?v=20260728120020): `WS100107?workPartIdList=...` で視聴済み状態を取得する。応答の `data.workPartList` の `workPartId` と `viewed` を参照する。
- [modal-player.js](https://animestore.docomo.ne.jp/js/cms/modal-player.js?v=20251112181100): `WS030101` の `partMeasure` を動画の再生時間として表示する。

未ログインのHTTP通信では、「正反対な君と僕」第8話の `WS100107` は結果86、`WS010105` は結果22でした。`WS030101` は話情報と `partMeasure` を返しました。認証を回避する処理は実装していません。

## 登録処理

1. `WS100107` で対象話がすでに視聴済みか照会する。
2. 未視聴なら `WS010105` でその話の更新先URLを取得する。
3. `WS030101` の `partMeasure` から話ごとの長さを取得する。固定の再生時間は使わない。
4. プレーヤーの開始通知・終了位置の終了通知・500ms後の位置0の終了通知を送る。
5. `WS100107` を最大3回照会し、`viewed === "1"` を確認できた場合だけ完了として次話へ進む。

上記の通知と視聴済み反映はユーザーによる動作確認済みです。サイトの内部条件は公開仕様ではないため、HTTP成功だけでは登録成功と扱わず、毎回視聴済み状態を照会します。

`resumeInfoUrl` はHTTPSの `animestore.docomo.ne.jp` とそのサブドメインだけを許可します。別ドメインが返る場合は停止し、権限を自動追加しません。Cookieはブラウザのログインセッションを利用し、認証情報や更新先URLを保存・ログ出力しません。動画本体・DRMライセンスは取得しません。

## 検証と制約

`node --test` で通知順序、各話の長さ、視聴済み照会、API拒否、更新先検証、停止、二重開始、ワーカー再起動を検証します。通信はモックです。

別作品で検証する場合は、ログイン済み環境で「更新前は未視聴 → 1話だけ登録 → 自動リフレッシュ後に視聴済み」を確認してください。コンプリート表示への反映も別途確認が必要です。未反映時は停止し、推測した追加通信を繰り返しません。

再生時間はサイトの秒単位の表示から求めるため、動画の正確なミリ秒単位の長さとは一致しない場合があります。停止後や通信切断後のサーバー側の反映は、サイトで確認してください。
