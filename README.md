# dAnimeCompletionHelper

dアニメストアで指定した範囲の話を、まとめて視聴済みに登録する非公式の Chrome / Microsoft Edge 拡張機能です。動画の再生や別タブの起動はせず、ログイン中のアカウントの視聴履歴を更新します。

## インストール

1. GitHub の「Code」→「Download ZIP」からダウンロードし、ZIPを展開します。
2. Chrome で `chrome://extensions`（Edge は `edge://extensions`）を開き、「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、`manifest.json` が入っているフォルダーを選びます。

読み込んだフォルダーは、拡張機能を使っている間は同じ場所に保管してください。

## 使い方

1. dアニメストアにログインし、作品ページを開きます。インストール前から開いている場合は、ページを再読み込みします。
2. 「気になる登録数」の下にある「まとめて視聴済み登録」を押します。
3. 開始話と終了話を指定し、「登録」を押します。

話数はエピソード一覧の先頭から1、2、3…と数えた順番で指定します。作品に表示される話数とは異なる場合があります。たとえば、一覧の先頭が「第13話」なら、開始話に「1」を指定するとその話から処理します。

すでに視聴済みの話はスキップします。全件の登録を確認すると、処理を開始した作品ページを自動で再読み込みし、表示を更新します。同じボタンをもう一度押すか、Escape キーを押すと操作欄を閉じられます。

## 停止とエラー

「停止」を押すと、後続の通信を中断します。すでに送信済みの更新は取り消せません。

エラーが出た場合や、送信後に視聴済み状態を確認できない場合は、その話で処理を停止します。ログイン状態とサイトの表示を確認してください。

停止・エラー時にはページを自動で再読み込みしません。また、処理中に開始元のタブを閉じたり、別の作品やサイトへ移動した場合も再読み込みしません。

## 更新

処理を停止してから、読み込んだフォルダーのファイルを最新版で上書きします。拡張機能の管理画面で再読み込みボタンを押し、dアニメストアの作品ページも再読み込みしてください。

## 注意点

- 初めて使う作品では、まず1話だけ登録し、表示への反映を確認してください。
- コンプリート表示への反映はサイト側の判定によります。
- サイトの仕様変更によって動作しなくなる場合があります。

## 開発

Node.js を用意し、このフォルダーで `node --test` を実行します。通信部分のテストにはモックを使っています。
